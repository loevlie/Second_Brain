# Open-Source Capabilities!

A new powerful open-source model **Mixtral-8x7b** was recently released and is now the third model to be added to GPT4Readability (the first open-source, locally run model)!

When you choose your model with the `-m` or `--model` argument use `local`.  

### Example of Using Mixtral-8x7b to Create a README file for my Repository

```bash
gpt4readability /path/to/repo -f readme -m local
```
